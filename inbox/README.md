# inbox/

Anything that doesn't fit an existing folder yet (constitution rule 24).

**Goes here**
- One dated file per topic, e.g. `2026-11-06-kids-college.md`. Start it with one line on what it is and why it didn't fit anywhere.

**Doesn't go here**
- Anything that fits another folder. Check each folder's README first.
- Mostly numbers. Those need a database table, so log an open question for a build session instead.

When three or more files here share a topic, propose a new folder (CLAUDE.md, "When something doesn't fit"). Cleared during the monthly review: each file gets filed, becomes a folder, or gets deleted with James's OK.
