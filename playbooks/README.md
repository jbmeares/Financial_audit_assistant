# playbooks/

Repeatable conversations. Each one is a short script: what to call, what to say first, and the one next action (constitution rule 10).

**Goes here**
- One file per routine conversation.
- Links to constitution rules, never copies of them, so the rules stay in one place.

**Doesn't go here**
- Tool reference. That goes in `tools/`.
- One-off conversations. If a conversation repeats, it earns a playbook.

| File | Use when |
| --- | --- |
| [weekly-check-in.md](weekly-check-in.md) | A routine weekly look at the money |
| [payday.md](payday.md) | Income just landed |
| [new-bill.md](new-bill.md) | A bill is new or has changed |
| [statement-upload.md](statement-upload.md) | Someone shares a statement |
| [monthly-review.md](monthly-review.md) | The monthly clean-up |

These are first drafts. The tools they name are built in Block F, so details may change once the tools exist.
