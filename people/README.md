# people/

One profile per person, built by interview. Read the profile of whoever is talking at the start of a session (CLAUDE.md, "Start of every session").

**Goes here**
- `<name>.md`, one per person: how they like things delivered, what they can change (constitution rule 20), and context they chose to share.

**Doesn't go here**
- Amounts, balances or dates. Those go in the database.
- Anything the person didn't say. Label inferences as **(inferred)** (rule 6).
- Fault or comparisons between people (rule 19).

Profiles are written in the interview threads (Block G).
