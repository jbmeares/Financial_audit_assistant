# life/

What happened and why it mattered. Read it before judging a hard stretch (constitution rule 23).

**Goes here**
- One file per event or period, e.g. `2026-q3.md`: what happened, how it affected the household, what was learned.
- Each dated amount mentioned here also gets a `log_life_event` row, so the database has the number and this file has the story.

**Doesn't go here**
- Amounts as the source of truth. Mention them for the story, but the database row is what counts (rule 21).
- Plans and goals. Those go in `strategy/`.
